# 🎓 Student Placement Predictor

ML model that predicts campus placement probability based on CGPA, DSA, Projects, Internship, Branch.

### Features
- Live probability prediction with Streamlit
- "What If" impact simulator - drag sliders to see effect  
- Personalized AI recommendations

### Tech Stack
Python, Streamlit, Scikit-learn, Logistic Regression

### Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
